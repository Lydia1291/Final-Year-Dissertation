# Kora — AI Mental Health Chatbot

Kora is an AI-powered mental health chatbot developed as my final year Computer Science project. The application allows users to have both text and voice conversations with an AI assistant designed to provide supportive, natural interactions.

Users can speak directly to Kora using voice input, and the chatbot responds with generated speech in real time, creating a more conversational and accessible experience. Alongside voice interaction, the application also supports traditional text-based chat.

I built the project using Python, JavaScript, HTML, and CSS, focusing on creating a responsive and user-friendly experience while integrating speech recognition, text-to-speech, and local LLM functionality.

## Features
* Voice-based conversations
* Real-time speech-to-text input
* AI-generated voice responses
* Text chat support
* Local LLM integration using Ollama
* Responsive web interface
